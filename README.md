# Тренажёр для технических собеседований

Отдельное приложение для подготовки к собеседованиям на frontend и fullstack.
В репозитории находится собственная копия движка, поэтому изменения здесь не
меняют приложение по аудиту.

## Запуск и сборка

```bash
pnpm install
pnpm dev
pnpm build:single:interview
pnpm type-check && pnpm lint && pnpm test
```

GitHub Pages публикует однофайловую сборку из `dist-interview`. Деплой запускается
при push в `main` и вручную через GitHub Actions.

## Структура

- `src/engine/` — интерфейс и движок заданий;
- `src/content/interview/` — вопросы, теория, карточки и план подготовки;
- `src/content/interview/deeplay/` — отдельная подготовка к вакансии deeplay: требования, 22 главы теории, кейсы и вопросы;
- `src/demos/interview/` — интерактивные демонстрации.

Сборка `build:single:interview` встраивает только пак собеседований в один HTML.

## Стандарт учебной теории

Теория должна быть одновременно подробной и понятной. Главная проверка качества — сможет ли читатель после главы объяснить механизм своими словами и применить его, а не только повторить названия API.

Каждую сложную тему раскрываем от простой модели к устройству: задача → понятная аналогия или схема → точные термины → пример с разбором → применение → ошибки и ограничения. Сокращения и жаргон расшифровываем при первом появлении. Детали «под капотом» включаем после базовой модели и отделяем публичное поведение от внутренних деталей реализации.

Для тем о версиях явно показываем, что появилось и изменилось в каждом поколении, какие возможности требуют конкретного минорного релиза, что осталось прежним и как выбирать API. Большие темы делим на карту и подробные главы. Полный редакционный шаблон и контрольный список находятся в [AGENTS.md](AGENTS.md).
